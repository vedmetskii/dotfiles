# It's my Dotfiles for saving my configs

## Dependences

Base dependences:

- lix
- home manager

Dependences for install this dotfiles:

- git
- make

## Pull configs

```bash
git clone https://github.com/vedmetskii/dotfiles ~/.dotfiles
cd ~/.dotfiles
```

## For install dependences (lix and home manager) and add configs use this command

```bash
make install
```

## For update configs use this

```bash
make
```
